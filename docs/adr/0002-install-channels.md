# Distribute via GitHub Releases, Homebrew, and Scoop

Developers must get `killport` onto macOS, Linux, and Windows without a language runtime. GitHub Releases carry the binaries for everyone; Homebrew covers macOS (and Linux); Scoop covers Windows developers. npm and winget were rejected for v1 to keep the number of channels we have to keep alive small; we can add them later if a real gap shows up.
